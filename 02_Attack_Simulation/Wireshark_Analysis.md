# 🌐 Wireshark SMTP Traffic Analysis

## 📌 Overview

Wireshark was used during this investigation to capture and analyze network traffic generated by the phishing email attack.

The objective was to observe SMTP communications between the attacker machine and the victim mail server, validate email delivery, and collect packet-level evidence for forensic analysis.

The captured traffic provided an independent source of evidence that complemented email header analysis, hMailServer logs, and Sysmon events.

<br><br>

# 🎯 Analysis Objectives

The primary goals of the Wireshark analysis were:

* Capture SMTP traffic generated during the attack
* Verify successful communication between attacker and mail server
* Validate email delivery at the network layer
* Observe SMTP protocol behavior
* Preserve packet evidence for future investigations
* Support IOC validation and attack timeline reconstruction

# 📧 SMTP Communication Observed

The packet capture confirmed that the attacker machine successfully communicated with the mail server.

Observed SMTP workflow:

```text id="vq58rt"
SMTP Session Initiated
        │
        ▼
HELO / EHLO
        │
        ▼
MAIL FROM
        │
        ▼
RCPT TO
        │
        ▼
DATA
        │
        ▼
Message Accepted
        │
        ▼
SMTP Session Closed
```

This sequence confirms that the phishing email successfully traversed the network and was accepted by the mail server.
